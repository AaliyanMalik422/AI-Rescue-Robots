# Scenario files

- `scenario_provided.txt` - the university file. Never edit it; it must load unchanged.
- `scenario_1_basic.txt`, `scenario_2_blocked_routes.txt`, `scenario_3_coordination.txt`,
  `scenario_5_resource_management.txt` - small custom scenarios.
- `scenario_4_stress.txt` - stress scenario (twice the provided dimensions).

All use the Appendix A format. Document any format extension in the main README.
